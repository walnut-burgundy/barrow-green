# barrow-green

Source-driven notes in the history of mathematics (`math.HO`).

The initial seed set is:

- June Barrow-Green
- Jesper Lützen
- Jed Z. Buchwald
- Jeremy Gray
- Athanase Papadopoulos

This repository is intentionally text-first. Its purpose is historical and mathematical source work, not visualization.

The recursive source-spider lives under [`history/`](history/README.md). It distinguishes material that has merely been located from material whose citations or bibliography have actually been inspected, records only verified citation edges, and keeps inaccessible or unfinished branches in an explicit recursion queue.

The repository is currently under `isomorphisms`; its intended long-term home is `isomorphismes`.
